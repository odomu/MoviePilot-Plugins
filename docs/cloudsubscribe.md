# 网盘订阅助手

网盘订阅助手是面向 MoviePilot v2 的多网盘订阅、转存和洗版插件。插件接管指定范围内的 MoviePilot
订阅搜索，按当前网盘的能力选择分享转存或离线下载，并复用 MoviePilot 的识别、命名、优先级和媒体服务器配置完成后处理。

## 能力范围

| 网盘 | 登录方式 | 分享转存 | ED2K/Magnet 离线 | PT 本地上传 | STRM 引用变量 |
| --- | --- | --- | --- | --- | --- |
| 115 | Cookie、扫码 | 支持 | 支持 | 支持 | `{pickcode}` |
| 123 | Token、扫码 | 支持 | 支持 | 支持 | `{file_id}`、`{md5}`、`{size}`、`{s3_key_flag}` |
| 夸克 | Cookie、扫码 | 支持 | 不支持 | 支持 | `{file_id}` |
| 光鸭 | Token、设备码登录 | 支持 | 支持 | 支持 | `{file_id}`、`{gcid}` |

其他主要能力：

- 同步电影和电视剧订阅，按缺失内容搜索、筛选、转存并生成历史。
- 支持 HDHive、Dian115、PanSou、聚影、SeedHub 和不太灵搜索源。
- 支持 115、123、夸克、光鸭分享以及网盘允许的 ED2K、Magnet 资源。
- 支持 MoviePilot 原生 PT/RSS 下载与整理，并可在整理完成后执行 PT 洗版上传。
- 支持 STRM、NFO、图片刮削、媒体服务器入库通知、Webhook 和 MoviePilot 整理历史。
- 提供任务列表、上传进度、后处理任务、历史记录、缓存、智能体工具和工作流入口。

## 环境与安装

- MoviePilot `2.14.6` 或更高版本。
- MoviePilot 已创建需要处理的电影或电视剧订阅。
- 容器可以访问所选网盘和已启用的搜索服务。
- 使用 STRM 时，MoviePilot 的本地媒体路径必须可写，并能被媒体服务器正确映射。

在 MoviePilot 插件市场添加仓库：

```text
https://github.com/odomu/MoviePilot-Plugins
```

安装“网盘订阅助手”。Release 包已包含前端产物，运行环境无需安装 Node.js。插件版本、最低 MoviePilot 版本和更新记录以 [
`package.v2.json`](../package.v2.json) 为准，Python 依赖见 [
`requirements.txt`](../plugins.v2/cloudsubscribe/requirements.txt)。

## 配置顺序

配置页分为“基础设置、转存设置、网盘配置、搜索设置、洗版设置、通知设置”。建议先保持插件关闭，完成网盘登录、转存路径、搜索源和本地路径配置后再启用。

### 基础设置

- “启用插件”控制定时同步和事件处理。
- “启用左侧导航”控制工作台入口，修改后需要刷新 MoviePilot 页面。
- “启用智能体工具”控制插件工具注册；关闭后旧工具实例也会拒绝执行。
- “写入整理历史”控制成功结果是否同步到 MoviePilot 整理历史。
- “定时执行 Cron”默认 `30 2,10,18 * * *`，即每天 `02:30`、`10:30`、`18:30`。
- “当前转存网盘”决定本轮使用的 provider、可选资源类型、登录配置和转存路径。

### 网盘配置

每个网盘独立保存凭据、转存路径和请求超时：

- 115：填写 Cookie 或扫码登录。转存路径是分享、离线和 PT 上传的暂存目录；慢操作超时同时覆盖分享、离线、上传等长请求。
- 123：填写 Token 或使用 123 App 扫码。插件使用 `p123client` 完成账号、文件、分享、离线和上传操作。
- 夸克：填写 Cookie 或扫码登录。夸克不声明离线下载能力，因此资源类型只显示夸克分享。
- 光鸭：填写 Access Token/Refresh Token，或使用设备码登录；Client ID 和 Device ID 会随凭据保存。

### 搜索设置

“搜索源优先级”决定查询顺序，已启用但未选择的来源排在末尾；“资源类型优先级”只展示当前网盘支持的类型。搜索结果会继续使用
MoviePilot `pri_order` 规则筛选和排序。

通用设置包括搜索缓存、缓存时间、跨来源并发和 Magnet 元数据地址模板。Magnet 必须先取得种子元数据并校验 Info
Hash，校验失败不会提交离线任务。

搜索源配置：

- PanSou：配置服务地址，可选认证、频道、插件、关键词过滤、结果数、并发、刷新和超时。
- HDHive：WebAPI 使用站点账号密码；OpenAPI 填写 Client ID、应用 Secret、Redirect URI，并通过 OAuth 获取
  `query unlock write` 权限。Access Token 过期后会使用 Refresh Token 自动刷新并写回插件配置，查询、解锁和签到均使用
  OpenAPI。
- Dian115：配置邮箱和密码；积分解锁默认关闭，开启后必须设置单次总预算和单订阅预算。
- 聚影：配置网页登录账号和密码，可设置候选上限和访问间隔。
- SeedHub、不太灵：无需账号，可限制候选数量。

积分解锁默认关闭。插件只在候选确实需要解锁且预算允许时消费积分

### 转存设置

- “订阅筛选模式”支持排除所选订阅或仅处理所选订阅。
- “单次最大转存文件数”限制一次同步的总文件数。
- “订阅并发数”控制不同订阅并行度，最大为 5；超出运行槽位的任务保留在队列中。网盘 provider、搜索源和批量转存并发只约束各自
  IO，不会把总任务槽位降低为 provider 并发数。
- “跳过其他季目录”避免电视剧分享中的无关季进入处理链。
- “本地媒体根路径”是 MoviePilot 容器内用于 STRM、NFO 和图片的真实可写路径。

开启“转存后直接生成 STRM”后配置基础地址和模板。通用变量包括 `{base_url}`、`{file_name}`、`{file_path}`，网盘专用变量见能力表。115
默认模板：

```text
{base_url}/d/{pickcode}?/{file_name}
```

NFO 和图片刮削是独立开关，不依赖彼此。

## 订阅接管与平台下载

插件可以接管 `subscribe_search`、`new_subscribe_search` 和 `subscribe_refresh`
，但不会修改订阅真实站点配置。接管开始/结束构成唯一时段，开始晚于结束时按跨天处理；开启“始终接管系统订阅”后忽略时段。“拦截新增订阅”独立控制新增订阅是否立即进入插件队列。

平台下载策略：

| 策略                  | 行为                                           |
|---------------------|----------------------------------------------|
| 允许 MoviePilot 下载并整理 | 接管态仍执行原生 PT/RSS 刷新、下载和整理；同订阅同季集已有网盘任务时阻止重复下载 |
| 阻止 MoviePilot 下载    | 接管态跳过原生刷新，并取消插件管理订阅进入的资源下载事件                 |
| 转为网盘离线下载            | 将可转换资源提交当前网盘离线任务；元数据不可用或提交失败时仍阻止平台下载         |

需要 PT 保种、MoviePilot 自动整理或 PT 洗版时，应选择“允许 MoviePilot 下载并整理”。旧版下载接管开关和开放时段会迁移到新的三态策略和单一接管时段，不再保留重复配置。

## 转存与后处理

分享资源直接进入当前网盘转存；ED2K 和 Magnet 进入离线任务。115 后处理按任务 Hash 直接查询详情，不再逐页扫描完整离线列表；20
秒轻量调度只检查已到期节点，并按渐进间隔回退。文件可见后，插件按 MoviePilot 分类和命名规则完成重命名、移动、STRM、刮削、历史与通知。

暂未完成的文件保存在持久化后处理队列。工作台可查看、重试或手动删除任务；删除后处理状态不会自动删除网盘文件、STRM
或订阅，只有历史删除操作明确选择“删除关联文件”时才处理关联产物。

任务列表显示普通订阅、网盘洗版和 PT 洗版：

- 网盘洗版显示“网盘洗版”标识、当前评分/搜索/转存阶段和后处理状态。
- PT 洗版显示“PT 洗版”标识、上传阶段、已上传字节、总大小、进度和实时上传速度。
- 运行中的 PT 上传可以从任务列表停止；停止检查覆盖文件校验和计算及分片上传过程，已经完成上传提交的文件不会被自动删除。
- 上传完成后任务进入统一后处理状态，直到网盘文件、STRM 和历史终态完成。

## 洗版设置

### 网盘洗版

“启用网盘洗版”处理网盘搜索候选。订阅必须已开启 MoviePilot 原生 `best_version`；未选择洗版范围时处理全部此类订阅，选择后只处理指定订阅。

插件以 MoviePilot `pri_order`、真实整理记录、插件转存历史、媒体库路径和真实网盘文件建立旧版本基线。无法确认旧网盘文件时不执行替换；没有旧版本的普通候选仍按正常转存处理。

### PT 洗版

“启用 PT 洗版”默认关闭。开启后监听 MoviePilot `TransferComplete`：只有带下载器和下载 Hash、且已整理到本地存储的 PT/RSS
文件才进入判断。符合 `best_version`、洗版范围和评分条件后，文件上传到当前网盘暂存目录，再复用统一替换与后处理链。

115、123、夸克和光鸭均支持 PT 上传。上传在后台执行，不移动或删除下载器源文件，不影响保种。电视剧只处理能明确识别季集的单集文件，季包或无法确认集号的文件会跳过。

洗版模式：

- 保留最大文件：评分相同仅在新文件更大时替换。
- 保留最小文件：评分相同仅在新文件更小时替换。
- 直接替换：满足优先级条件后替换旧版本。
- 新旧共存：保留旧文件，并为新版本生成不冲突的名称。

“评分自愈间隔”用于刷新洗版基线。PT 洗版没有找到旧网盘文件时，可将符合条件的本地文件作为新的网盘版本上传。

## 通知与历史

- “发送消息通知”控制 MoviePilot 消息，并可选择通知类型。
- “启用入库通知”在 STRM 或目标文件就绪后通知所选媒体服务器，不执行全库扫描。
- Emby 媒体信息提取使用 MoviePilot 中已配置的 Emby 服务。
- 媒体服务器路径映射每行使用 `媒体服务器路径#MoviePilot 路径`。
- Webhook 支持 GET/POST、独立地址和超时。

历史页支持筛选、通知、重试、单条/批量删除和从历史或媒体服务器内容发起手动网盘洗版。运行中的后处理历史允许删除其任务状态；关联文件删除必须由用户单独选择。

## 平台入口

- 侧栏工作台：运行任务、PT 上传进度、历史、手动资源、离线任务和缓存管理。
- 远程命令：`/cloud_sync`、`/cloud_status`、`/cloud_link`、`/cloud_cache_clear`。
- 智能体：查询状态、启动同步、搜索与选择资源、提交链接、清理缓存和更新配置。
- 工作流：执行订阅搜索或处理上下文中的资源链接。
- 仪表板：显示运行摘要、任务和转存统计。
