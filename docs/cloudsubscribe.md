# 网盘订阅助手

网盘订阅助手是面向 MoviePilot v2 的网盘订阅插件。插件根据网盘实际能力组合搜索、转存、离线下载和文件处理流程，当前提供
115 网盘实现。

## 使用前提

- MoviePilot `2.14.6` 或更高版本。
- 已在 MoviePilot 中创建需要处理的电影或电视剧订阅。
- MoviePilot 容器能够访问 GitHub、115 及已启用的搜索服务。
- 使用 STRM 时，MoviePilot、媒体服务器和 115 直链服务之间的路径与网络必须互通。

## 主要功能

- 同步 MoviePilot 电影、电视剧订阅，按缺失集搜索和转存。
- 支持 HDHive、Dian115、PanSou、聚影、SeedHub 和不太灵搜索，资源类型支持 115、ED2K 和 Magnet。
- 支持 115 分享转存、离线下载、扫码登录、任务管理和批量文件操作。
- 按 MoviePilot 分类与命名规则生成目录、文件名和 STRM。
- 支持并发任务、搜索缓存、负缓存、离线后处理和聚合通知。
- 使用 MoviePilot `pri_order` 执行洗版评分，并结合整理历史、转存历史和媒体库路径判断现有版本。
- 提供 Vue 配置页、运行页、仪表板和可关闭的侧栏工作台。
- 支持 MoviePilot 智能体工具、工作流动作和远程命令。

## 安装与更新

在 MoviePilot 插件市场中添加仓库：

```text
https://github.com/odomu/MoviePilot-Plugins
```

在插件市场找到“网盘订阅助手”并安装。MoviePilot 会从 GitHub Release 下载与当前版本匹配的
`cloudsubscribe_v<version>.zip`，无需在运行环境中构建前端。

更新插件前先确认 `package.v2.json` 已显示新版本。若插件市场仍显示旧版本，可刷新插件市场缓存后再执行更新。插件更新会替换插件程序，
已保存的 MoviePilot 插件配置不会因普通更新自动清空。

插件版本、最低 MoviePilot 版本和更新记录以 [`package.v2.json`](../package.v2.json) 为准；Python 依赖见
[`requirements.txt`](../plugins.v2/cloudsubscribe/requirements.txt)。

## 首次配置

建议按以下顺序完成配置，确认前一步正常后再开启下一项能力。

### 1. 登录 115

进入“网盘配置 → 115 网盘”：

1. 在“115 Cookie”中直接填写 Cookie，或点击二维码按钮扫码登录。
2. 确认账号卡片能够显示用户及容量信息。
3. 设置“网盘转存路径”。115 分享、ED2K 和 Magnet 会先进入该目录，处理完成后再按 MoviePilot 分类规则移动。

Cookie 属于敏感凭据，不要写入文档、日志、截图或 Git 仓库。账号失效时重新扫码即可，不需要卸载插件。

### 2. 配置搜索源

至少启用一个搜索源：

- `PanSou`：默认启用。填写服务地址；服务开启认证时再填写用户名和密码。默认查询 115 与 ED2K。
- `HDHive`：支持 OpenAPI 和 CloakBrowser 两种模式。OpenAPI 使用应用/OAuth 参数；CloakBrowser 使用站点账号密码。
“搜索源优先级”决定查询顺序；未选择但已启用的来源会排在末尾。“资源类型优先级”默认是：

```text
115 分享 → ED2K → Magnet
```

Magnet 必须通过配置的元数据地址取得种子内容并校验 Info Hash，验证失败时不会提交到 115。

### 3. 配置转存与 STRM

- “单次最大转存文件数”限制一次同步最多处理的文件数量。
- “订阅并发数”默认 `2`，最大 `5`；初次使用建议保留默认值。
- “批量转存数量”控制单批提交规模。
- “跳过其他季目录”可避免电视剧资源中的无关季被转存。
- “本地媒体根路径”应填写 MoviePilot 容器内实际可写、且媒体服务器能够映射访问的路径。

开启“转存后直接生成 STRM”时，需要配置：

- STRM 基础地址，例如 `http://172.17.0.1:9527`。
- STRM URL 模板。115 可使用 `{pickcode}`；通用变量包括 `{base_url}`、`{file_name}`、`{file_path}`。

默认模板为：

```text
{base_url}/d/{pickcode}?/{file_name}
```

NFO 和图片刮削为独立开关。仅需要 STRM 时无需同时开启。

### 4. 设置订阅范围

“订阅筛选模式”支持：

- 排除所选订阅：除列表中的订阅外均可由插件处理。
- 仅处理所选订阅：只有列表中的订阅进入插件流程，适合首次小范围验证。

首次启用建议选择“仅处理所选订阅”，先用一个电影或一季电视剧验证目录、命名、STRM 和通知结果。

### 5. 启用插件

完成以上配置并保存后，再打开“启用插件”。默认 Cron 为：

```text
30 2,10,18 * * *
```

即每天 `02:30`、`10:30`、`18:30` 执行。可以在侧栏工作台手动启动同步，并通过运行状态与历史记录确认处理结果。

## 订阅接管

- 插件接管 MoviePilot 的 `subscribe_search`（追更）和 `new_subscribe_search`（新增）调度入口，不修改订阅的真实站点配置。
- 接管时段内，符合过滤规则的搜索进入插件队列；开放时段或明确排除的订阅仍由 MoviePilot 原生处理。
- “拦截平台资源下载”与“接管平台资源下载”是两个独立功能。前者只阻止接管范围内的 MoviePilot 下载；后者把平台选中的资源转为
  Magnet 并提交到网盘离线任务，同时阻止重复下载，接管失败时也不放行平台下载。
- 开启“拦截新增订阅”后，新增订阅的 `N` 状态搜索即使不在接管时段内也进入插件队列。
- 新增任务只处理 `N`，追更任务只处理 `R`，不会因系统定时任务重复扫描其他状态。
- 插件卸载或停用时恢复被接管的原始调度函数。

“始终接管系统订阅”关闭时，默认时段为：

- 接管：`18:00` 至 `23:59`
- 开放：`00:00` 至 `17:30`

开放时段内由 MoviePilot 原生搜索处理。若希望全天由插件接管，可开启“始终接管系统订阅”。“拦截新增订阅”是独立开关，开启后新增订阅
即使位于开放时段也会进入插件队列。

## 搜索与资源处理

- 搜索源顺序可配置，未启用的来源不会进入调用链。
- PanSou 的 `cloud_types` 根据统一资源类型优先级自动生成，无需单独配置；Magnet 取得并校验种子元数据后才允许提交。
- 搜索结果、负缓存、网盘路径、分享状态、候选资源和 Magnet 元数据使用 MoviePilot `TTLCache`，并按 region 隔离。
- 分享资源优先执行网盘转存；ED2K 和 Magnet 进入离线下载与后处理流程。
- STRM 仅用于确认本地文件存在；大小和质量优先来自 MoviePilot 整理历史、插件转存历史及媒体库路径。

默认开启搜索缓存，缓存时间为 `30` 分钟，跨搜索源并发数为 `2`。重复调试搜索结果时可清理插件缓存；不建议长期关闭缓存或盲目提高并发，
115 API 和积分解锁仍会保持串行限速。

PanSou 默认参数：

- 内部并发：`20`
- 每种资源类型结果数：`10`
- 单次最多解析前 `100` 条原始结果
- 搜索超时：`30` 秒
- 强制刷新：开启

如果 PanSou 来源较多且经常超时，不要先降低内部并发；可以适当增加超时时间。重复搜索更关注速度时，可关闭“强制刷新”以使用 PanSou
服务端缓存。

## HDHive 积分解锁

HDHive 的“自动积分解锁”默认关闭。开启前必须同时设置：

- 单次积分总预算：限制本轮同步允许消耗的积分总量。
- 单订阅积分预算：限制单个订阅允许消耗的积分。

插件只会在当前资源确实需要解锁且预算允许时继续。历史上的“已解锁”状态不代表当前分享仍然有效，插件仍会检查当前预览和分享状态。

CloakBrowser 模式还可配置候选上限、详情页并发、预览超时和页面访问间隔。页面访问间隔用于统一限速并加入随机抖动，不建议设置过低。

## 洗版

- “启用网盘洗版”处理电影和电视剧的网盘候选替换。
- 开启网盘洗版后，默认覆盖全部已开启原生 `best_version` 的电影和电视剧订阅；选择洗版范围后仅处理指定订阅。`best_version`
  决定订阅是否属于洗版订阅，插件范围只负责进一步限制处理对象。
- 洗版模式支持“新旧共存”“直接替换”“保留最大文件”“保留最小文件”。评分更高时执行洗版；评分相同时，最大或最小模式按文件大小决定是否替换，默认保留最大文件。

评分基线优先读取 Emby 项目详情中的实际媒体大小，并结合真实整理记录和插件转存记录确定优先级；同时只校验平台目标目录中的真实网盘文件是否存在。没有真实网盘文件时不执行替换，按普通转存处理。

## 通知与媒体服务器

- “发送插件通知”控制 MoviePilot 内的插件消息。
- “启用入库通知”会在 STRM 写入成功后通知所选媒体服务器，不触发全库扫描。
- Emby 可额外开启媒体信息提取，通过 PlaybackInfo 接口触发。
- 媒体服务器路径与 MoviePilot 本地路径不一致时，每行填写一条映射：

```text
/媒体服务器/strm#/strm
```

- Webhook 支持 `POST` 和 `GET`，可独立设置地址与超时。启用前先确保目标服务能够安全接收插件发送的数据。

## 平台入口

- 远程命令：`/cloud_sync`、`/cloud_status`、`/cloud_link`、`/cloud_cache_clear`。
- 智能体：查询运行状态、启动同步、搜索和选择资源、清理缓存、更新配置及提交资源链接。
- 工作流：执行网盘订阅搜索，或处理工作流上下文中的资源链接。
- 仪表板：显示轻量运行摘要。
- 侧栏页面：提供任务状态、历史筛选、手动资源和离线任务管理，可在基础设置中关闭。

关闭“启用智能体工具”后，插件不再注册新的智能体工具，运行中的旧工具实例也会拒绝继续执行。关闭“显示左侧导航”后需要刷新 MoviePilot
主界面，侧栏入口才会更新。

## 常见问题

### 安装成功但页面空白

确认 MoviePilot 版本满足要求，并检查以下地址是否能够返回 JavaScript：

```text
/api/v1/plugin/file/cloudsubscribe/dist/assets/remoteEntry.js
```

若返回 `404`，通常表示安装的 Release ZIP 缺少前端构建产物，应重新安装正确的 Release 版本。

### 搜索不到结果

依次检查：搜索源是否启用、认证信息是否有效、订阅是否被筛选规则排除、资源类型是否被选中，以及搜索源服务是否能从 MoviePilot 容器访问。
PanSou 开启认证但未填写用户名密码时会直接认证失败。

### 转存成功但没有 STRM

检查“转存后直接生成 STRM”、本地媒体根路径、STRM 基础地址和模板。还应确认 MoviePilot 容器对本地目录有写权限，并检查历史记录中是否存在
重命名、移动或文件后处理错误。

### 媒体服务器没有收到更新

确认已开启入库通知并选择媒体服务器。路径不一致时配置路径映射；Emby 媒体信息提取依赖 MoviePilot 中有效的 Emby 配置。

### 任务长期处于处理中

在侧栏工作台查看运行状态、离线任务和历史记录。115 离线任务尚未完成时，插件会等待后处理；确认任务失败后再使用重试或删除功能，避免重复提交。
